# Nimbus — concept AI startup landing page

Concept landing page for a **fictional** AI meeting assistant. Designed and built by Nafis A.

- Next.js 15 (App Router) + React 19, static export, hosted on GitHub Pages
- Reusable components: Navbar, Hero, Features, HowItWorks, Pricing, Faq, Footer
- Interactive: live "typing" product preview, step tabs, monthly/yearly pricing toggle, accordion FAQ, mobile menu
- Plain CSS, no UI framework; respects reduced-motion settings

```bash
npm install
npm run dev     # local development at http://localhost:3000
npm run build   # static site in ./out
```

Nimbus and all customer names are fictional.
